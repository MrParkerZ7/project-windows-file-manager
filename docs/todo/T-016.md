## Context

T-003's adversarial review (2026-09-25) found five style roles that consumer specs ask the component library for and
that T-003's own catalogue never listed. Each consumer spec's rule is to raise the need to T-003 rather than author the
style locally, so each would otherwise block. They are parked here, not built inside T-003, because none is in T-003's
plan and none is needed by T-004, the next consumer - build this before T-006 / T-008 / T-011, whichever comes first.

## The five roles

| Key (T-001 shape) | Asked for by | What it is | Grounding |
|---|---|---|---|
| `Broadsheet.Style.Button.RowAction` | T-006 (`T-006.md:416`) | a row's remove action, hidden at rest and shown while its row is hovered or keyboard-focused; `BasedOn` `Button.LinkMuted` | T-006's design; not drawn in 3a |
| `Broadsheet.Style.Toggle.Link` | T-008 (`T-008.md:272`) | a link-looking `ToggleButton` with a checked state - the Preview header's `Auto ✓` | artboard `:200` |
| `Broadsheet.Style.Toggle.Flag` | T-008 | a compact chip `ToggleButton` for a rule's flags (`Aa`, `.*`), accent when on | artboard rule rows `:210-211` |
| `Broadsheet.Style.CheckBox.Large` | T-006 | the 16 px `Include subfolders` box - the artboard draws it with the design system's 16 px `.radio .dot` | artboard `:157`; `styles.css` `.radio .dot` |
| `Broadsheet.Style.TouchTarget.Small` | T-011's acceptance row on T-003 | `MinWidth`/`MinHeight` 24 for glyph-sized controls | T-011 |

**Not needed:** T-011's `Broadsheet.FocusVisual.OnAccent`. T-003 shipped `Broadsheet.Style.FocusVisual.Inset`, a
two-tone ring (2 px Accent with a 1 px Bg line inside) that reads on an Accent fill, and the outer ring on a filled
button sits on the page ground, where Accent already clears 3:1.
