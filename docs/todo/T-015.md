## Context

Found while verifying `T-010a` (help-markup balance check across all five payloads), then confirmed in the parser.
Not a drift defect — the text is *true* — so it was out of `T-010a`'s scope, and no other ticket in `G-001` owns it.
Filed by the generative drain rather than fixed inline.

The `MATCH BY NAME REGEX` help payload (`src/WindowsFileManager/Views/MainWindow.xaml:1031`) uses **8 `<code>`
tags**. The help grammar supports exactly four: `<h>`, `<b>`, `<w>`, `<link>`.

`FormattedTextBehavior`'s parse loop has no unknown-tag branch. When a tag is not recognised it falls through to:

```csharp
AddPlainText(textBlock, text[tagStart..(tagEnd + 1)]);
```

— which emits the raw tag text. So the user sees the literal characters `<code>` and `</code>` rendered in the
popup, eight times. (`AddStyledRun`'s `switch` also has no `default`, but that path is never reached for `<code>`;
the tokenizer rejects it first.)

## Acceptance criteria

- [ ] The `MATCH BY NAME REGEX` popup renders with no literal tag markup visible.
- [ ] Chosen fix is one of: (a) drop the `<code>` tags and use `<b>` for the same emphasis, or (b) add `code` to the
      grammar with a monospace `Run` in `AddStyledRun`. **(a) is the smaller change and needs no new code under the
      coverage gate; (b) adds a grammar feature and a `FormattedTextBehavior` branch that must be tested to 100%.**
- [ ] A balance/known-tag check is run over **all** `Tag=` help payloads, not just this one, so a second unsupported
      tag elsewhere is caught in the same pass.
- [ ] `docs/specs/SPEC-010-contextual-help.md` is updated in the same commit — its grammar section states the
      supported tag set, and its "Not implemented" section notes whether unknown-tag handling is now defined.
- [ ] If (b): `FormattedTextBehavior` is in the measured coverage scope (`Helpers*`), so the new branch needs tests.
- [ ] Build clean under `TreatWarningsAsErrors`; tests green.

## Risks

Low. The honest trap is choosing (b) for elegance: it adds a public grammar feature, a new `Run` style, a spec
change and a 100%-coverage obligation, to fix eight characters of stray markup in one popup.

## Out of scope

The wider captions-and-popover restructuring of all 84 help sites — that is `T-010` Stage B.
