## Concept

Four contextual-help strings in the shipping UI describe behaviour the code does not have. One of them tells the user
that Delete is **permanent and cannot be undone** when the code routes to the Recycle Bin and records an undoable
history entry. That is a live user-facing correctness defect, and it has no dependency on any part of the 3a redesign.

Split out of T-010 on the coherence pass's recommendation: *"The Delete popup's false 'permanent, cannot be undone'
claim is a live user-facing correctness defect; there is no reason it waits behind six tasks. The A/B split is the
single best structural decision in the epic."*

## Design

Pure string edits in the `Views/MainWindow.xaml` help payloads plus the matching doc rows. No C#, no styles, no
layout, no new types - therefore nothing new under the coverage gate. Commits with an explicit pathspec, so it lands
cleanly past the uncommitted test batch without touching it.

## Detail

1. **Delete popup** - remove the "permanent / cannot be undone" claim; state that files go to the Recycle Bin and the
   action is undoable from History. Cross-check `docs/SECURITY.md:347`, which already records the true behaviour.
2. **Custom Rules popup** (`MainWindow.xaml:1094`) - rename the actions `Contains` to `Include` and `Ignore` to
   `Exclude`, and restate the precedence sentence to match the first-match-wins loop at `MainViewModel.cs:3018-3031`
   (break at `:3029`). The current "Ignore ALWAYS overrides Contains" wording describes a precedence model the code
   no longer implements.
3. **Match-types popup** - reconcile against the six folder match types actually implemented.
4. **Folder-search popup** - reconcile against `SearchFoldersAsync` (`MainViewModel.cs:3213+`), including the
   depth-limit behaviour.
5. **README.md** - the same Contains/Ignore to Include/Exclude rename in the feature tour.

## Interfaces / contracts

Consumes nothing. Publishes nothing. Touches only string literals and docs - deliberately zero coupling to T-001's
token layer, so it can land in Wave 0 while the resource-key contradictions (C1-C3) are still being settled.

## Acceptance criteria + Case-Coverage Matrix

- [ ] The Delete popup no longer claims permanence; it names the Recycle Bin and the History undo.
- [ ] `MainWindow.xaml:1094` and README use Include/Exclude, and the precedence sentence matches first-match-wins.
- [ ] The match-types and folder-search popups match implemented behaviour.
- [ ] `docs/specs/SPEC-010-contextual-help.md` is updated in the SAME commit (repo sync rule).
- [ ] `dotnet build` is clean under TreatWarningsAsErrors; `dotnet test` still green.
- [ ] Committed by explicit pathspec; the 11-file test batch is untouched and still dirty afterwards.

| Case | Success | Fail |
|---|---|---|
| Delete popup (required) | text matches recycle+undo behaviour | any residual "permanent" / "cannot be undone" wording |
| Rules popup (required) | Include/Exclude + first-match-wins | old vocabulary or old precedence claim survives |
| Match types (required) | all six types described as implemented | a described type that does not exist |
| Folder search (required) | depth limit + stop/clear described | omits the depth limit |
| README (required) | renamed | stale vocabulary |
| SPEC-010 (required) | updated same commit | spec lags the string change |
| Boundary - empty help payload | renders nothing, no crash | null-ref |

## Edge cases

A help payload using the `<h>` / `<w>` / `<link>` markup grammar must keep valid markup after the edit -
`FormattedTextBehavior` parses it, and a malformed tag renders as literal text to the user (the same class of defect
as the known unsupported `<code>` tag in the MATCH BY NAME REGEX popup).

## Dependencies

None. This is a Wave 0 task by design.

## Risks

Low. The only real risk is editing a string whose behaviour claim is *also* wrong in the spec - mitigated by checking
each claim against the cited source line before rewriting it, not against the existing doc.

## Out of scope

The captions-and-popover restructuring of all 84 help sites - that is T-010 Stage B, which needs the rebuilt frame.
