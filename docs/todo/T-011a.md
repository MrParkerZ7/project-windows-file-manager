## Concept

The audit that has to happen *before* the token dictionary is frozen. T-001 writes the palette; if the contrast
verdicts arrive afterwards, T-001 ships twice. The coherence pass put this in Wave 0 for exactly that reason.

## Design

Read-only analysis producing three artifacts that T-001 and T-003 consume as inputs: a contrast table, a token role
list, and a keyboard navigation model for the tool-window grid.

## Detail

1. **Contrast audit** - every foreground/background pair the 3a artboard specifies, measured against WCAG 2.2 AA
   (4.5:1 body, 3:1 large text and non-text UI). Report each as pass/fail with the measured ratio, and for each fail
   name the Broadsheet ramp step that fixes it. No invented colours.
2. **Token role list** - the sixteen role keys T-001 must publish, named by **ramp role**
   (`Broadsheet.Brush.Accent2`), never by semantics (`Destructive`). A semantically-named colour key is the first row
   of the deferred 4a layer.
3. **Keyboard navigation model** - tab order across the 260/1/1fr/1/360 grid, keyboard access to the two splitters
   (which do not exist today), and focus-visual requirements for every new control type.

## Interfaces / contracts

**Publishes:** the contrast table, the sixteen-key role list, and the navigation model.
**Consumed by:** T-001 (palette values + key names), T-003 (focus visuals), T-011 (implementation + verification).

## Acceptance criteria + Case-Coverage Matrix

- [ ] Every artboard colour pair has a measured ratio and a pass/fail verdict.
- [ ] Every fail names a real Broadsheet ramp step as its fix - no invented colour.
- [ ] The role list uses ramp names only; no semantic colour names.
- [ ] The navigation model covers both splitters and states the focus-visual contract.
- [ ] Fork 1 is answered (or its recommendation taken under auto-approve) before T-001 starts.

| Case | Success | Fail |
|---|---|---|
| Body text pairs (required) | at least 4.5:1 or a named ramp fix | unmeasured pair |
| Large text / non-text (required) | at least 3:1 or a named ramp fix | unmeasured pair |
| Role naming (required) | ramp names only | a semantic name leaks in |
| Splitter keyboard access (required) | reachable and operable | mouse-only |
| Boundary - a pair no ramp step fixes | escalated as a decision | silently shipped failing |

## Edge cases

A pair that no ramp step can fix is a genuine fork for the user, not a value to invent - escalate rather than pick.

## Dependencies

None. Wave 0.

## Risks

Deferring this past T-001 means re-freezing the dictionary. That is the whole reason it is split out.

## Out of scope

Implementation. Focus visuals, `AutomationProperties` and the manual pass are T-011.
